# JanVaani-AI


Core Features

1. Voice-Based Complaint Registration

Citizens can speak naturally instead of filling lengthy forms manually.

2. Native Language Support

Users can communicate in supported Indian languages, with speech-to-text conversion and translation where needed.

3. AI Complaint Classification

Identify complaint categories such as electricity, water supply, roads, sanitation, and public services.

4. Department Routing

Suggest the appropriate department based on complaint content, with citizen confirmation before submission.

5. Conversational AI Assistant

Guide users through missing details, explain the complaint process, and provide spoken responses.
